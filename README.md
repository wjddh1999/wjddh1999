## Featured Project

### R.I.P — Rusty Iron Project

Unity 6 기반 3D 메카 액션 프로젝트입니다. 고속 이동, 전투 파이프라인, 하드 록온과 Photon Fusion 2 기반 PvP 흐름을 구현하고 있습니다.

- CharacterController 기반 지상·공중 기동
- Quick Boost / Assault Boost와 에너지 관리
- Projectile · Shield · Armor · ACS 전투 처리
- Hard Lock 후보 탐색과 Lag Compensation
- State Authority 기반 데미지·승패 판정
